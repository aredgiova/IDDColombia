# Blog: extensión de lectura

Modo Read. El usuario pide migrar las tres publicaciones públicas de su blog y optimizarlas para SEO. La dirección institucional y cercana está confirmada; se conserva el sistema existente. La petición precisa de contenido y continuidad visual no reabre conceptos ni requiere una comp generada.

Índice con introducción breve, una lectura principal sobre juventud con su fotografía original, seguida de iglesia y familia. La selección principal es editorial, no una afirmación de actualidad. Artículos con título, autoría y fechas verificadas, imagen original, texto de lectura continua y enlaces a otras publicaciones. No hace falta buscador para tres textos cortos.

Contenido sustantivo conservado. Las notas de borrador sobre testimonios o recursos inexistentes se guardan en el registro de migración y no se presentan como contenido terminado. No se inventan testimonios, autores, fechas ni credenciales. El logo original del artículo Iglesia se muestra completo, sin recortar ni sustituirlo por una foto inventada.

SEO: rutas legibles, metadata propia, canonical, Open Graph, BlogPosting y BreadcrumbList, sitemap, enlaces internos y redirecciones permanentes desde las rutas originales. Las previews siguen sin indexación. No hay promesa de ranking ni publicación externa en esta etapa.

Responsive desde 320 px, texto de aproximadamente 65–75 caracteres, foco visible, imágenes locales optimizadas y dimensiones explícitas. Se entrega el índice y tres artículos completos en el servidor local existente, con revisión de escritorio y móvil.
